# Ω-PLASMA-001 — Emergent Structure / Vacancy Stability / 等离子体涌现结构与空位稳定性

RU: Синтетическая проверка самоорганизации и устойчивости структур связей.
EN: Synthetic test of self-organization and stability of relational structures.
中文：关系结构自组织与稳定性的合成验证。

## Purpose
Test whether a dynamic relational system can spontaneously form a stable structure and preserve a persistent structural defect after removal of one node.

## Scientific status
PREREGISTERED — no experimental result is claimed yet.

## Core hypothesis
H1: Dynamic link adaptation can produce a stable collective structure and preserve a vacancy after removal of a node.

## Null hypothesis
H0: Removing a node necessarily drives the system toward relaxation without a persistent structural defect.

## Protocol
1. Fix model and parameters before runs.
2. Generate independent initial states.
3. Run baseline without deletion.
4. Remove the central node in the intervention group.
5. Measure structural displacement, vacancy lifetime, connectivity and stability.
6. Repeat across noise and coupling regimes.
7. Report PASS/FAIL only from preregistered criteria.
